# Docker Compose UI

Docker Compose UI — Docker Compose үстіндегі жеңіл веб-интерфейс және HTTP API. Docker Compose CLI-мен үйлесімді және бөлек дерекқорсыз бір контейнерде жұмыс істей алады.

## Architecture / Архитектура

```text
Browser -> Docker Compose UI HTTP service -> docker-compose CLI -> Docker Engine -> application containers
```

## Project structure / Структура проекта

- `static/` — web assets
- `demo-projects/` — example Compose projects
- `screenshots/` — UI captures
- application code — HTTP API and Docker Compose integration
